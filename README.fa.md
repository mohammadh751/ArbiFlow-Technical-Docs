# ArbiFlow — Public Case Study

نسخه عمومی و گزیده معرفی پروژه ArbiFlow.

این مخزن برای نمایش دامنه مسئله، تکامل معماری، اصول مهندسی مالی و شواهد منتخب ساخته شده است. سورس موتور، الگوریتم‌ها، پارامترها، قراردادهای داخلی، گزارش‌های خام و داده‌های حساب در این نسخه منتشر نمی‌شوند.

- Website: https://mohammadh751.github.io/ArbiFlow-Technical-Docs/
- Languages: Persian / English
- Exchanges studied: Wallex / Bitpin / Nobitex
- Evidence basis: historical 0.2.79 and V3 records, exchange research catalogue, and R5.68 A10.38.13 qualification snapshot.

**محدودیت امنیتی:** این یک وب‌سایت عمومی است و جلوگیری قطعی از کپی، اسکرین‌شات یا استخراج محتوا را تضمین نمی‌کند. حفاظت اصلی از طریق منتشرنکردن جزئیات قابل بازسازی انجام می‌شود.
