# ArbiFlow — Public Case Study

A curated public overview of the ArbiFlow project.

This repository presents the problem domain, architecture evolution, financial-engineering principles and selected evidence. The trading engine source, proprietary algorithms, parameters, internal contracts, raw reports and account data are not included.

- Website: https://mohammadh751.github.io/ArbiFlow-Technical-Docs/
- Languages: Persian / English
- Exchanges studied: Wallex / Bitpin / Nobitex
- Evidence basis: historical 0.2.79 and V3 records, exchange research catalogue, and the R5.68 A10.38.13 qualification snapshot.

**Security limitation:** This is a public website and cannot guarantee prevention of copying, screenshots or content extraction. The primary protection is not publishing reconstructive details.
